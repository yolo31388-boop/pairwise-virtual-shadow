# pairwise-virtual-shadow

开放世界阴影在远处闪烁、细长物体漏影、角色自阴影断裂：虚拟阴影页按固定 128 页；页分配按对象 ID；LOD 切换不迁移阴影页；方向光缓存按相机位置；细长物体页覆盖不足；角色骨骼烘焙频率和动画不同步；页面失效用帧数；透明遮罩没写深度；多光源共用页池；远距离阴影精度不降。render/virtual_shadow.py 是核心，tests/test_virtual_shadow.py 15个红。要修的是：按屏幕投影分配页；页对象键；LOD 页迁移；世界锚定缓存；细长包围盒；骨骼时间采样；时间失效；遮罩深度；分光源页池；距离精度。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
